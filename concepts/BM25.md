# BM25 score model (positive-IDF, normalized single-field profile)

A finite-corpus lexical scoring model combining positive inverse document frequency, saturated term frequency and document-length normalization, with distinct query terms.

**Notation:** idf(t)=ln(1+(N-df(t)+1/2)/(df(t)+1/2)); K(d)=k₁(1-b+b·L(d)/avgL); score(q,d)=Σ_{t∈q} idf(t)·tf(t,d)/(tf(t,d)+K(d)).

## Mathematical formulation

idf(t)=ln(1+(N-df(t)+1/2)/(df(t)+1/2)); K(d)=k₁(1-b+b·L(d)/avgL); score(q,d)=Σ\_{t∈q} idf(t)·tf(t,d)/(tf(t,d)+K(d)). Finite vocabulary T and finite nonempty corpus C of distinct document IDs. tf:T×D→ℕ; L(d)=Σ\_{t∈T}tf(t,d)>0 for each d∈C; N=|C|; avgL=(Σ\_{d∈C}L(d))/N>0; df(t)=|{d∈C:tf(t,d)>0}|. Score only corpus documents. k₁>0 and 0≤b≤1 ensure positive denominators on C. Query q is a finite SET of terms: repetitions have no additional weight. Exact real logarithm/arithmetic, one field, no boosts, phrase scoring or query-frequency factor. This selected Lucene-style normalization omits (k₁+1); multiplying every score by that positive query-independent factor preserves ranks. RSJ unshifted IDF is a different convention and can be negative. Empty corpus and zero-length corpus documents are excluded in this profile, rather than assigning arbitrary averages. SQLite FTS5 weighted-column phrase scoring is the distinct BM25FTS5 profile; the positive-IDF single-field convention here is unchanged.

**Lean formulation** (in its source module context):

```lean
structure BM25 (T : Type u) (D : Type v) [Fintype T] where
  docs : Finset D
  tf : T → D → ℕ
  nonempty : docs.Nonempty
  positiveLength : ∀ d ∈ docs, 0 < ∑ t, tf t d
  k1 : ℝ
  b : ℝ
  k1_pos : 0 < k1
  b_range : 0 ≤ b ∧ b ≤ 1
```

**Source:** [`Catalog.BM25`](../lean/Catalog/RetrievalDecisions.lean); consulted 2026-11-20.

**Scope:** model

**Interpretation:** BM25 T D stores a finite corpus, natural counts and parameter restrictions. bm25Length/Average/DF derive statistics, bm25IDF/Term/Score implement the displayed exact-real formula. unitBM25 is a concrete one-token, one-document model with k₁=1,b=0.

**Limits:** The registered realization is a minimal nonempty corpus; it proves the admissibility constraints and uses definitional statistics/scoring, not assumed scoring-law fields. Lean functions extend outside corpus documents using Lean total division; catalog guarantees are restricted to d∈C.
