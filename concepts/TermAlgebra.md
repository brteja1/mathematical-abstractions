# Free ranked term algebra with variables

Finite syntax trees generated by variables and operation symbols with a specified finite arity.

**Notation:** T_Σ(X)=μT.(X+Σo:Σ. T^{Fin(arity(o))})

**Stable ID:** `urn:csabs:concept/TermAlgebra`

**Categories:** Types and semantics

**Kind:** Abstract data type

**Prerequisites:** [Sum Type](SumType.md), [Dependent pair (Sigma type)](DependentPair.md), [Dependent function (Pi type)](DependentFunction.md), [Structural Induction](StructuralInduction.md)

**Related concepts:** [Predicate Logic](PredicateLogic.md), [Finite ordered rose tree](RoseTree.md)

## Interface and scope

**axiomBasis:** var(x)≠app(o,ts); var(x)=var(y)⇔x=y; app(o,ts)=app(p,us) iff o=p and the transported child families agree; P(var(x)) for all x and ((∀i,P(ts(i)))⇒P(app(o,ts))) for all o,ts imply ∀t,P(t); eval(ρ,F,var(x))=ρ(x); eval(ρ,F,app(o,ts))=F(o)(λi.eval(ρ,F,ts(i)))
