# Well Founded Relation

A relation for which every nonempty subset has a minimal element with respect to that relation.

**Notation:** ∀S⊆A, S≠∅ ⇒ ∃m∈S ∀x∈S: ¬(x R m)

**Stable ID:** `urn:csabs:concept/WellFoundedRelation`
